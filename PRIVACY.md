# Privacy Policy

This repository handles data in accordance with GDPR and Danish data protection law.

## Data Minimization
- Only necessary personal data is collected and stored.
- All informant/transcript data is **pseudonymized** as \Informant 1, 2...\ — direct identifiers removed.
- No CPR numbers, private addresses, or sensitive personal data is stored in this repository.

## Evidence Handling (where applicable)
- Business data (e.g., public webshop snapshots) contains only **publicly available** business information (CVR, business address, public policies).
- Customer personal data is **not** collected — only aggregated product and policy evidence.

## Retention
- Personal data is retained only as long as necessary for the academic/legal purpose and then deleted.
- For questions about data handling, open a private security advisory.

## Your Rights
Under GDPR you have the right to access, rectify, and erase your personal data. Contact the repository owner via a private GitHub Security Advisory.
